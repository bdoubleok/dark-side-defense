Updated 2025 Seahawks / Mike Macdonald validation: this defense is not pressure-first. It is a disguise-first, coverage-first, split-safety pattern-match ecosystem that uses simulated pressure selectively as a constraint—not as the base identity.

  • POUND — foundational Quarters ecosystem
  • STUFF — Cover 6 / Half-Quarter-Quarter ecosystem
  • 3 LOCK — Match 3 / Buzz / weak rotation ecosystem
  • DANGER — universal match-distribution rules engine
  • SITE / ROB / LOU — weak-rotation match-3 changeups

Core calls: Quarters, Cover 6, Match 3, weak rotation, simulated pressure. Sim pressures complement coverage—they do not define you.

Do Not Overuse: Cover 0, static spot-drop zones, repeated fire-zone blitzes, pressure every snap, or calling the same sim twice in a row.

CFB '26 Formations available in-game only. Nickel 2-4 Odd is Madden-only—approximate with Nickel 2-4, Nickel 2-4 Dbl Mug, 3-3-5 Over Flex, or Nickel 3-3 Over.

  • Nickel 3-3 Over — core base (POUND / 3 LOCK hub)
  • Nickel 2-4 — stand-up edge / weak-rotation substitute for Madden Nickel 2-4 Odd
  • Nickel 2-4 Dbl Mug — disguise / SITE / pressure constraint
  • Nickel 3-3 Dbl Mug — A-gap disguise / Match 3 pressure
  • 3-3-5 Over Flex — Trips / Bunch / overhang control
  • Nickel 3-3 Mint — anti-RPO / spread run
  • 3-3-5 Mint — safety-heavy run support
  • 3-3-5 3 High Odd — 3-safety disguise / Cover 6 / sim pressure
  • Dime Rush — long yardage / weak rotation / sim pressure
  • 3-4 Bear — short yardage only
  • Goal Line 5-3 / 6-2 — goal line only
Not in CFB '26: Nickel 2-4 Odd, Big Nickel Over G (Madden packages). Do not list 4-2-5 Over as equivalent to Big Nickel Over G.

Madden '26 Supports more NFL-style odd/mug spacing. Map the same coverage ecosystems; CFB approximates odd looks via Nickel 2-4 and 3-3-5 spacing.

  • Nickel 2-4 Odd — primary weak-rotation / stand-up edge base Madden-only
  • Nickel 2-4 Dbl Mug — SITE / sim constraint
  • Nickel 3-3 Cub — Quarters / match hub (verify in-game label)
  • Big Nickel Over G — separate package; not 4-2-5 Over
  • Dollar 3-2 Mug — dime disguise / pressure
  • Dollar 3-2 — long-yardage quarters
  • Dime Normal — Dime Rush equivalent
  • 3-4 Bear — short yardage only

Translate CFB Nickel 2-4 + Over Flex calls to Madden Nickel 2-4 Odd + Big Nickel Over G when you need true NFL mug/odd spacing.

POUND Quarters Foundation

Meaning: Split-safety Quarters match rules—#2 horizontal, #1 vertical, cloud/flat conflict solved post-snap.

Calls: Cover 4 Quarters · Cover 4 Palms · Match Quarters · Quarters Match

Formations: Nickel 3-3 Over, 3-3-5 Over Flex, Dime Rush

When: Spread 10/11, empty, 2nd & medium, protect deep sidelines.

Avoid: vs heavy run fits without Mint; static spot drops; Cover 0 pairing.

STUFF Cover 6 / HQH

Meaning: Half-Quarter-Quarter—field Quarters, boundary Cover 2 / invert rules; trips/bunch answer.

Calls: Cover 6 · Cover 6 Willie · Cover 6 Match · Cover 2 Invert · Cover 4 Palms

Formations: Nickel 2-4, 3-3-5 3 High Odd, Nickel 3-3 Over

When: Trips, bunch, field-heavy formations, shot plays (shade over top).

Avoid: Overcalling vs 12/21 without run fit; pure spot Cover 2.

3 LOCK Match 3 / Buzz

Meaning: Weak rotation, buzzed hook/curl, match routes to flat and seam—Macdonald's change-up shell.

Calls: Cover 3 Match · Cover 3 Buzz Mable · Cover 3 Buzz · Match Buzz · Cover 3 Seam

Formations: Nickel 3-3 Over, Nickel 2-4, Nickel 3-3 Dbl Mug, 3-3-5 Over Flex

When: RPO teams, 2TE spread, QB run, intermediate flood.

Avoid: Static Cover 3 Sky as every-down answer; no buzz vs levels.

DANGER Match Distribution Engine

Meaning: Rules that assign #1/#2/#3 across zones—who takes crossers, seams, and flats after disguise.

Calls: Cover 3 Match · Cover 3 Seam · Match 3 · Cover 3 Sky (low priority only)

Formations: All nickel; especially Dbl Mug and 2-4

When: Conflict looks, empty, mesh, levels, scramble contain sets.

Avoid: Sky as primary; man-free without robber plan.

SITE ROB LOU Weak-Rotation Changeups

Meaning: SITE = weak rotation to field/boundary; ROB = robber insert vs crossers; LOU = louis weak rotation tag (verify in-game terminology).

Calls: Cover 1 Robber · Cover 1 Hole · Nickel Dog 3 Buzz · Cover 3 Match (weak spin)

Formations: Nickel 2-4 Dbl Mug, Nickel 3-3 Dbl Mug, Nickel 2-4

When: 2nd & long disguise, red zone, anti-scout weeks, QB hi-lo reads.

Avoid: Cover 0 spam; pairing complex pressure with complex robber every snap.

PACK Split Safety Zone — Quarters/Half Hybrid

Meaning: Split Safety Coverage that applies Quarters tools to the Nickel side and Half tools away from the Nickel. Nickel aligns to passing strength and runs C.O.S. motion. GP adjustment available for Speed Trips and Detroit formations.

Quarters Tools (Nickel side): Quads (Zone It) · Read (Buddy) · Stump · Box  |  Half Tools (away): Cloud · Read · Choke

By formation: Strong → Quarter Tools · Weak → Half Tools · 3x1 → Quads / Read / Stubbie / Stump · Bunch → Box · Snug → Zone It / Read Buddy + Cloud or Read Buddy · Speed / Empty → Stubbie / Stump + Cloud / Read

Position keys: WC — Cloud/Smack (#1 oversplit = Smack, #2 detached = Soft Squat) · SC — Quads = MOD #1 Bail; Stubbie = MEG #1; Stump = Clue 1/3 · Nickel — Quads = Quarter Flat; Read = Read Flat (Wall #2); Stubbie = Soft Squat · SS — Quads = Quarters 1×12 O/S #2; Read = 2 to 1 Read; Stubbie = 3 to 2 Read · FS — Cloud/Choke = Deep 1/2 Field; Read = 2 to 1 Read · MIKE — Quads = Quarter Hook; Read/Stump = #3 Vertical Hook; Stubbie = Read Hook (Wall #3) · DIME — Cloud/Smack = Vertical Hook #2; Read = Read Flat (Wall #2)

When: Split-field answer vs trips, speed personnel, and formation-strength conflict — one side demands Quarters match, the other demands Cloud/Half protection.

Avoid: Applying the same tool family to both halves; ignoring formation strength declaration pre-snap.
