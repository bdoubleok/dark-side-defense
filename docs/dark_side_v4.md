## Concept Glossary (7 Tokens)

| Token | CFB Calls | Structure | When to Use |
|-------|-----------|-----------|-------------|
| **DANGER** | Cover 3 Match, Cover 3 Sky | 1-high match distribution | Universal rules engine — who takes crossers, seams, flats after disguise |
| **3 LOCK** | Cover 3 Match + press adjustments | 1-high, all CBs press | Weak rotation, buzzed hook/curl, RPO teams, QB run |
| **POUND** | Cover 4 Quarters, Cover 4 Palms | 2-high quarters | Spread 10/11, empty, protect deep sidelines |
| **STUFF** | Cover 4 Palms + adjustments, Cover 6 | 2-high asymmetric | Trips, field-heavy formations, split-field |
| **CLOUD** | Cover 2 Invert, Tampa 2 | 2-high invert | Change-up, safe two-high, run support from cloud |
| **SQUAT** | Cover 4 Palms (vs Bunch) + adj | 2-high tightened | **Bunch = SQUAT. Always.** |
| **SAND DEUCE** | Edge Blitz 3, Sim Pressure 3 | 5-man sim pressure | Constraint every 4–5 plays — not the identity |

**ROBBER** (related): Cover 1 Robber, Cover 1 Hole — man-free with middle rob.

---

## Golden Rules

1. Never show the same look twice in a row.
2. Alternate 1-high (DANGER / 3 LOCK) and 2-high (POUND / STUFF / CLOUD).
3. Mix in SAND DEUCE (Edge Blitz 3) every 4–5 plays.
4. **Bunch = SQUAT. Always.**
5. Red zone = STUFF or SQUAT.
6. Hurry-up = Simplify to DANGER + POUND only.
7. Make the QB think every single play.

## 3 LOCK #3 Decision Tree

Count #3 from the sideline before every snap.

| Read | Action | Detail |
|------|--------|--------|
| #3 in backfield (2×2) | STAY in base 3 Lock | Standard match-3 rules |
| #3 declared to trips (3×1) | FLOOD rules activate | Trips flood adjustment |
| #3 + RB same side (Quads) | CHECK to Pound | 4 receivers to one side — quarters tools |
| No #3 (Empty) | STAY or CHECK to Pound | Consider 5th rusher / dime look |
| #3 away (Bunch weak) | CHECK to SQUAT | Bunch kills pattern-match — tighten |

## Recipes (7 Disguise Sequences)

1. **Show Blitz (A-Gap Disguise)** — Any zone from Over/Mint → Dbl Mug next snap. Show interior pressure, rotate post-snap.
2. **Delayed Post-Snap Rotation** — Call DANGER (Buzz Mable) → safety rotates after snap. QB reads pre-snap shell wrong.
3. **POUND ↔ STUFF Disguise Pair** — Alternate POUND (C4 Qtrs) and STUFF (C6). Identical 2-high pre-snap, different post-snap.
4. **D-Line Stunts (Stunt-First)** — Any zone → D-Line Stunts menu. 24.5% stunt rate — stunts over volume blitzing.
5. **Mint Personnel Rotation** — Alternate Nickel 3-3 Mint (CB apex) and 3-3-5 Mint (safety apex). Same tite front, different apex.
6. **SQUAT vs Bunch** — See Bunch → Call C4 Palms → Tighten with BOX/BUDDY tools. Never pattern-match bunch raw.
7. **3 LOCK #3 Pre-Snap Read** — Before every snap: count #3 from sideline. Apply decision tree before confirming call.

## Philosophy Rules (8)

1. **Coverage First. Always.** — 80.4% zone. No concept over 30%: DANGER ~30%, POUND ~25%, STUFF ~20%.
2. **Sniper Blitz — Shoot to Kill** — Rank 26 blitz rate. #1 efficiency when you do bring pressure.
3. **Never the Same Look Twice** — Alternate 1-high (DANGER / 3 LOCK) and 2-high (POUND / STUFF / CLOUD).
4. **POUND ↔ STUFF Disguise** — Both 2-high pre-snap. Identical shell, different post-snap match rules.
5. **Bunch = SQUAT. Always.** — Pattern-match dies against bunch rub routes. Tighten immediately.
6. **Stop the Run from Two-High** — #1 run defense + 50.9% light box. Don't need 8-man box every snap.
7. **Hurry-Up = Simplify** — No-huddle: reduce to DANGER + POUND only. No complex robber/pressure combos.
8. **Recruit the Chess Piece** — 300+ slot snaps, 250+ LB, 80+ edge. Build around the hybrid safety.
